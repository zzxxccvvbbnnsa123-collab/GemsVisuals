PULSE OVERLAY — ПРОТОТИП ДЛЯ ANDROID

ВАЖНО
Это исходный код, не готовый APK. Меню пока демонстрационное и не управляет Minecraft. APK нужно собрать и проверить на телефоне.

ЧТО ЕСТЬ В ПРОТОТИПЕ
- плавающая кнопка поверх других приложений;
- перетаскивание кнопки;
- компактное тёмное меню;
- декоративные частицы;
- закрытие меню нажатием вне него;
- уведомление Android при работе оверлея.

СБОРКА БЕЗ КОМПЬЮТЕРА ЧЕРЕЗ GITHUB ACTIONS
1. Распакуй этот ZIP на телефоне.
2. В браузере открой https://github.com и войди в аккаунт.
3. Создай новый публичный репозиторий с названием PulseOverlay. Не добавляй README, .gitignore или лицензию.
4. Открой репозиторий → Add file → Upload files.
5. Загрузи СОДЕРЖИМОЕ папки PulseOverlay, а не сам ZIP. В корне репозитория должны быть build.gradle, settings.gradle, gradle.properties, папка app и папка .github.
6. Нажми Commit changes.
7. Открой вкладку Actions. Если GitHub попросит включить Actions, подтверди.
8. Открой workflow “Build Pulse Overlay APK” и нажми Run workflow, если сборка не началась автоматически.
9. Дождись зелёной галочки у сборки, открой её запуск и найди раздел Artifacts внизу.
10. Скачай PulseOverlay-debug-apk, распакуй скачанный архив и установи app-debug.apk.
11. В настройках Android разреши Pulse Overlay отображаться поверх других приложений. Затем запусти приложение и проверь его работу.

ЕСЛИ СБОРКА УПАЛА
Открой запуск в Actions, найди первую красную ошибку и пришли скриншот. Не меняй версии Gradle наугад.

ОГРАНИЧЕНИЯ
- Это тестовый APK, не публикуй его как готовый продукт.
- Для установки Android может попросить разрешение на установку неизвестных приложений для браузера/файлового менеджера.
- Даже если APK соберётся, работу оверлея на конкретном телефоне нужно проверить.
